# contextFonts

Nix flake packaging non-free fonts from the release assets of this repo
(tag `0.2`, see `nix/sources.nix`). **Do not redistribute the outputs.**

| Package | What |
| --- | --- |
| `contextFonts` (default) | Adobe Font Folio 11 + Emigre Triplex OTFs in `share/fonts/opentype` (NixOS `fonts.packages`, ConTeXt) |
| `minmath` | TeX Live package: typoma Minion Math + Minion Pro text (`\usepackage{minmath}`, options `myriad`, `triplex`, `mathonly`) |
| `triplex` | TeX Live package: Emigre Triplex Sans/Serif (`\usepackage{triplex}`, families `triplexsans`, `triplexserif`) |
| `mtp2` | TeX Live package: MathTime Pro II complete (`\usepackage{mtpro2}`) |
| `optima` | TeX Live package: Optima LT Std from the Font Folio (`\usepackage{optimalt}` → `\sfdefault`, `[rm]` for main text; family `optima`, series m/mb/db/b/k/ub) |
| `palatino` | TeX Live package: Palatino LT Std from the Font Folio (`\usepackage{palatinolt}` → `\rmdefault`, `[sf]` for sans slot; family `palatino`, series l/m/mb/b/k, small caps in m) |
| `trajan` | TeX Live package: Trajan Pro from the Font Folio (`\usepackage{trajan}` → `\trajanfamily`, `[rm]`/`[sf]` to make it a default family; family `trajan`, series m/b, `\textsc` = all small caps, no italic) |
| `minion` | TeX Live package: Minion Pro from the Font Folio (`\usepackage{minion}` → `\rmdefault`; family `minion`, series m/mb/sb/b + condensed c/mbc/sbc/bc, shapes n/it/sc, automatic optical sizes Capt/Text/Subh/Disp) |
| `myriad` | TeX Live package: Myriad Pro from the Font Folio (`\usepackage{myriad}` → `\sfdefault`, `[rm]` for main text; family `myriad`, weights l/m/sb/b/k × widths normal/c/sc/sx, shapes n/it) |
| `adobeFontFolio`, `triplexOtf` | the two halves of `contextFonts` |

## NixOS

```nix
fonts.packages = [ inputs.contextFonts.packages.${system}.contextFonts ];
```

## TeX Live

The TeX packages carry the attributes of nixpkgs' `texlivePackages`
(`tlOutputName`, `fontMaps`, `tlDeps`), so they go into `withPackages`:

```nix
let cf = inputs.contextFonts.packages.${system};
in pkgs.texliveSmall.withPackages (ps: [ ps.latexmk cf.minmath cf.triplex cf.mtp2 cf.optima cf.palatino cf.trajan cf.minion cf.myriad ])
```

With devenv's `languages.texlive`, extend the package set so the names resolve:

```nix
languages.texlive.base.withPackages = f:
  pkgs.texliveSmall.withPackages (ps: f (ps // { inherit (cf) minmath triplex mtp2 optima palatino trajan minion myriad; }));
languages.texlive.packages = [ "minmath" "triplex" "mtp2" "optima" "palatino" "trajan" "minion" "myriad" ];
```

`\usepackage[mathonly]{minmath}` sets up only Minion Math and leaves the text
fonts alone, e.g. with Palatino text (any load order):

```latex
\usepackage{palatinolt}
\usepackage[mathonly]{minmath}
```

Math operators (`\sin`), digits in math and `\mathrm` remain Minion Pro.

`\usepackage[triplex]{minmath}` needs the `triplex` package in the same env
(Triplex Sans scaled by `\triplexscale`, 1.08 with minmath, 1 otherwise).

The style files are `optimalt.sty` / `palatinolt.sty` because TeX Live's
psnfss already ships an (obsolete) `palatino.sty`. They and `trajan.sty` are
generated by `nix/otf-text-package.nix`, a generic otftotfm builder for OTF
text families; every generated style file also defines `\<family>family`
(`\optimafamily`, `\palatinofamily`, `\trajanfamily`, `\minionfamily`,
`\myriadfamily`).

`minion`/`myriad` are independent of `minmath`, which builds its own
`minionpro`/`myriadpro` families for its math setup: they use other family
names and TFM names (`*-cf-*` vs `*-lf-*`), so all three can share one TeX
Live env (the shared PFB file names are byte-identical).

`overlays.default` adds all packages to a nixpkgs instance (needs `allowUnfree`).

## Test documents

`devShells.default` has pdfLaTeX/latexmk with `minmath`, `triplex`, `mtp2`,
`optima`, `palatino`, `trajan`, `minion` and `myriad`,
plus `just` and `pdffonts`:

```sh
nix develop -c just testdocs   # -> tests/out/<name>.pdf
```

Each recipe (`just minmath`, `just triplex`, `just mtp2`, `just optima`,
`just palatino`, `just trajan`, `just minion`, `just myriad`) fails unless the
expected fonts are embedded, no Type 3 (bitmap) font was used and no glyph
was reported missing. Sources are in `tests/`.
